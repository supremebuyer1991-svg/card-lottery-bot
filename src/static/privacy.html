プライバシーポリシー

トレカ抽選ナビ（https://tcg-chusen.com、以下「当サイト」）は、ポケモンカード・ワンピースカードなどの抽選販売の情報と相場をまとめるサイトです。当サイトでの個人情報などの取り扱いは次のとおりです。

アクセス解析について

当サイトは、Googleによるアクセス解析ツール「Googleアナリティクス」を使っています。Googleアナリティクスはクッキー（Cookie）を使って、ページの閲覧状況などのデータを集めます。このデータは匿名で集められ、個人を特定するものではありません。クッキーはブラウザの設定で無効にできます。くわしくはGoogleのポリシーと規約をご覧ください。

広告（アフィリエイト）について

当サイトは、Amazon.co.jpを宣伝しリンクすることによってサイトが紹介料を獲得できる手段を提供することを目的に設定されたアフィリエイトプログラムである、Amazonアソシエイト・プログラムの参加者です。また、楽天アフィリエイトなどのアフィリエイトプログラムにも参加しています。これらの事業者は、商品への興味に応じた情報を表示するためにクッキーを使うことがあります。

このブラウザの中だけに残る記録

「応募した」の印などは、お使いのブラウザの中だけに保存され、当サイトのサーバーには送られません。

YouTube・SNSについて

当サイトは、YouTube API サービスを使って、当サイトが作った相場ランキングなどの動画を、運営者自身のYouTubeチャンネルに投稿しています。閲覧者の方のYouTubeのデータを集めたり使ったりすることはありません。YouTubeの利用にはYouTube利用規約とGoogleプライバシーポリシーが適用されます。

掲載情報について

抽選の情報や相場は、各お店の告知や公開されている取引の情報をもとにまとめていますが、正確さを保証するものではありません。応募の前に、必ず各お店の公式の告知をご確認ください。当サイトの情報によって生じた損害について、当サイトは責任を負いかねます。
