## SEOの方針（11/14 Fable の監査＋点検。3日ごとの見直しはこれに沿う）
- 勝てる言葉：A. JAN・型番、B.「商品名 買取」（/premium/）で登録数と信頼をためる。C.「モデル名＋再販・在庫・抽選」（モデルの常設まとめ）、D.「新作＋予約・特典」（/new/）で稼ぐ。E. お店・施設＋予約（/l/）。「Switch2 抽選」などの大きな言葉は狙わない（game8・電撃・インプレス）
- やらないこと：データの無い商品にAIの文で文字数を足す／中身が変わらないのに更新日を変える／店×カテゴリ×商品の組み合わせでページを自動で増やす／終わった受付を大量に検索に出す／Product の構造化データ（販売価格が無い）／他サイトの説明の長い転載／転売をすすめる言葉
- 毎週見る数字：Search Console の登録済み数と「クロール済み未登録」、ページ種類ごと（premium／モデルまとめ／new／l）の表示・クリック・順位、「再販・在庫・抽選・予約」を含む言葉の表示回数、GA4 の affiliate_click（ネットワーク別・ページ種類別）、検索から来た人1人あたりのクリック、材料なしのAI解説の件数（0を保つ）、定価が本当の定価の商品数
- 4週間：1週目（〜11/21）デメリットのない改善1〜9（11/14 済み）・GA4のカスタムディメンション登録・8〜10を決める／2週目 モデルの常設まとめを10モデルで／3週目 表示が出たモデルから30へ・「商品の特徴」を表示のある商品から先に／4週目 8〜20位のページの題名と説明を個別に直す・年末の新作を /new/ で
- 決まったこと（11/14 ユーザー）：A. モデルの常設まとめ → OK（10モデルで開始。models.yaml の hubs）／B. 家電 → 残す（「家電・カメラ」ジャンル kaden を作った。Xには出さない）／C. トップの「定価以上で売れる」の基準と言い回し → いまのまま
- 気をつけること（11/14）：検索の表示・クリックがあるページを noindex にしない（「ジャンルなしの薄いページは noindex」にしたら、いちばんクリックされている /premium/4902370919127/ が外れた。すぐ戻した）。noindex を足すときは、Search Console の上位ページに当たらないか先に確かめる
- （以前の）ユーザーの判断待ち（11/14）：8. モデル単位の常設まとめ（どのモデル）／9. ゲーム・ホビー以外の家電（スマホ・カメラ・炊飯器など約130件）を消すか、カテゴリを作るか／10. トップの「定価以上で売れる」の基準（本当の定価が分かる商品だけにするか）と「激熱🔥」などの言い回し
