## 2. 絶対のルール
1. **Xに投稿するのは、ユーザーが「投稿して」「予約して」と言った時だけ。** 「作って」は下書きだけ（APIの投稿はお金がかかる）。
2. **リンク付きの投稿は、Xの予約投稿機能（ブラウザ操作）で入れる**（例：1分後〜数分後）。規約違反でないことはユーザーが確認済みで、いつもそうしている。
3. **Xの速報で、リンク先の商品とサイトに載せている商品を違わせない。** 信用に関わる。11/10に別の商品のAmazonリンクで速報してしまい、削除した。
4. **サイトにも投稿にも、間違った情報を出さない。** 11/10、ちいかわの記事に無い「通販で先着販売」を作ってしまった。今は game_verify で元の記事と照らし合わせて確かめている（下記）。
5. 投稿の本文に「（PR）」を入れない（プロフィールに「PRを含む」と書いてあるため）。
6. Secrets には触らない。
7. 動作確認で変わったローカルの状態ファイルは、`git checkout -- state/` で元に戻す（state をコミットしない）。

## 4. ゲーム・ホビー入荷速報（@a9994aaa）の方針
- 対象はゲーム機＋ホビー（ガンプラ・ちいかわ・ベイブレードなど）。範囲は入荷Now（nyuka-now.com）を参考にする。
- **サイトのトップ（/）は「プレミア商品一覧」**（定価以上で売れる商品）。抽選一覧は /chusen/。
- 買取相場（/souba/）は値動きが中心（値上がり・値下がり＋カテゴリごと）。プレミア商品一覧と中身を被らせない。
- 商品ページ（/premium/<JAN>/）に載せるもの：
  - 相場・定価・JAN・解説・FAQ
  - 上部に Amazon・楽天のボタン。速報から来た人は `?x=az|rk` でその店を目立たせる
  - メルカリのリンク
  - いちばん高く売れる買取店へのリンク（目立たせすぎない）
- 買取価格は、kaitori-search.app・kaitori.app に**載っているお店のサイト**から取る。まとめサイト自体は使わない（config/game/kaitori_stores.yaml）。
- **X投稿の条件**
  - 定価以上で売れる商品か、品薄の商品（抽選・招待・3日以上の売り切れ）のときだけ。
  - 一番くじは投稿しない。
  - 販売速報は「売り切れ→販売」に切り替わった時だけ（売り切れを1回見ていればよい）。前から売っていたものに「販売開始」と出さない。
- **ポケカ・ワンピースカード**
  - 大手のお店の抽選に限って、ゲーム垢で扱ってよい。
  - ページはゲームサイト側に別に作る（/pokeca/、/onepiece-card/）。文言もゲーム垢向けにする。
  - x-queue.json に入れて予約投稿する（見つけて3分後と、受付開始の時刻）。
- **元の記事で確かめる（src/game_verify.py、11/10 追加）**
  - 新しく見つけた抽選・販売の情報は、AIが元の記事を読み直して確かめる。確かめる項目はお店・商品・種類・日時・通販か店頭か。
  - 記事と合うものだけ `verified=True` にする。合わないもの・販売の情報でないものは `verified=False` にして、サイトに出さない。
  - Xの速報と予約キューは `verified=True` のものだけ。
- GA4 の ID は G-Q760DX5QF4。Search Console に登録済み。

## 5. 主なファイル
- `src/main.py`：入口。`src/game_pipeline.py`：ゲーム側の流れ。
- `src/sitegen.py`（トレカ）・`src/sitegen_game.py`（ゲーム）：サイトを書き出す。x-queue.json もここで作る。
- `src/game_premium.py`：プレミア商品・商品ページ・相場ページ。
- `src/game_kaitori.py`・`src/game_souba.py`：買取店の読み取り。ルデヤ・モバイル一番・ケータイゴッド・トゥインクル・SY・TOJO はAIを使わない決まった読み方。
- `src/game_affi.py`：楽天・Amazon・メルカリのリンク。
- `src/game_xpost.py`：ゲーム垢のAPI速報。
- `src/game_aitext.py`：中身の少ない商品ページに解説を足す。
- `src/game_volume.py`：ページごとの中身の量を測る（/content-report.html）。
- `src/game_upcoming.py`：発売予定（楽天ブックス、/new/<JAN>/）。
- `src/game_verify.py`：元の記事で確かめる。
- 設定：`config/settings.yaml`（トレカ）、`config/game/settings.yaml`・`categories.yaml`・`kaitori_stores.yaml`（ゲーム）。
- 調べ物用ワークフロー：
  - `probe-game.yml`：ページの中身を見る。`raw:`・`text:`・`URL##body` が使える。
  - `x-post-game.yml`：`?` で見張りの状態、`-` で記録だけ、`@` で直近の投稿を見る。
